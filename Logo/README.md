# Artes Openfix

Os originais desta pasta são preservados. Para preparar os arquivos usados no site,
execute na raiz `python ops/prepare-brand-assets.py` (requer Pillow).

| Original | Aplicação |
| --- | --- |
| `Imagem do ChatGPT 26 de out. de 2026, 23_08_55-1.png` | Símbolo transparente no sistema, ícone do navegador, e-mails e PDF |
| `Imagem do ChatGPT 26 de out. de 2026, 23_08_55-2.png` | Logo horizontal colorida no cabeçalho, login, cadastro e imagem de compartilhamento |
| `Imagem do ChatGPT 26 de out. de 2026, 23_15_50-2.png` | Logo horizontal branca no rodapé escuro |
| `Imagem do ChatGPT 26 de out. de 2026, 23_08_57-4.png` | Ícones do aplicativo para Apple e manifesto |
| `favicon.ico` | Favicon original fornecido |

O preparo recorta as margens transparentes e gera tamanhos adequados para a web.
As demais imagens permanecem como referências e alternativas da marca.
